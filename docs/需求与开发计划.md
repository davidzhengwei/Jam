## 1. 产品定位

| 项 | 说明 |
|---|---|
| 使用者 | 单人（你自己），一台 Windows 电脑 |
| 核心价值 | 把「知识点 + 代码片段」放在一个地方，找得快、贴得顺、复制出去直接能用 |
| 使用形态 | 便携版 exe，数据与程序同目录，整个文件夹拷走 = 迁移/备份 |
| 设计取向 | 稳定 > 功能多。宁可少一个功能，不要丢一次数据 |

## 2. 明确的边界（第一版不做）

- 不做登录、注册、主密码、密码保险箱
- 不做云同步、多端、协作分享、移动端
- 不做插件系统、AI 写作、Markdown 双栏预览
- 不做自动更新（手动替换 exe 即可）

理由：单人本地场景下，这些只会增加故障面。

## 3. 典型使用场景（验收时按这四条走）

| 场景 | 操作路径 | 期望 |
|---|---|---|
| A 记知识点 | 分区「Java」→ 新建页面「线程池参数」→ 写文字 + 贴一段代码 | 代码自动高亮，标题进树，重启还在 |
| B 存代码片段 | 分区「代码库」→ 页面「常用 SQL」→ 粘贴 30 行 SQL | 高亮正确、缩进不乱、点复制直接粘进 IDE 能跑 |
| C 找东西 | 任意页面按 Ctrl+K → 输「线程池」 | 150ms 内出结果，回车跳转并定位到命中处 |
| D 迁移备份 | 关掉软件 → 拷整个文件夹到 U 盘 | 另一台电脑双击 exe，内容一字不差 |

## 4. 功能需求清单

### P0 —— 第一版必须交付

**F1 三级目录结构（笔记本 / 分区 / 页面）**

- 新建、重命名、删除、拖拽排序（跨分区拖动页面、跨笔记本拖动分区）
- 分区可设颜色（OneNote 观感），页面显示标题 + 修改时间
- 删除进入「回收站」，可还原或彻底删除；彻底删除需二次确认
- 验收：建 3 层结构、拖动排序、重启后与关闭前完全一致

**F2 富文本编辑器**

- 支持：标题 H1-H3、加粗、斜体、下划线、删除线、行内代码、有序/无序列表、待办清单、引用、分割线、表格、超链接、代码块
- 粘贴自 Word / 网页时去掉花哨样式，只保留结构（避免带一堆内联样式）
- 验收：每种格式重启后完整保留；粘贴到微信/Word 结构不乱

**F3 代码块（核心卖点，对标博客园）**

- 语言下拉选择（内置 30+ 常用语言），未选时按 plaintext 处理
- 语法高亮、行号、语言徽标 + 行数显示
- 代码块右上角「复制」按钮，一键复制全部代码
- Tab / Shift+Tab 整体缩进与反缩进；回车自动继承上一行缩进；行尾为 `{ ( [ :` 时自动多缩进一级；仅输入 `}` 时自动回退一级
- 粘贴纯文本进代码块：保留原始空格与换行，不解析 Markdown
- **粘贴自动识别语言**：整段文本粘贴进空代码块时，按特征打分自动选语言（见下表），识别置信度低则保留 plaintext，不干扰手打
- 复制出去是纯文本，缩进与换行 1:1 保留
- 验收：贴 200 行 Java 不卡顿、语言自动识别为 java；复制出来的代码可直接编译

**语言自动识别规则（优先级从高到低，命中即定）**

| 特征 | 判定 |
|---|---|
| `<?php` | php |
| `#!/bin/bash` / `#!/bin/sh` | bash |
| `#include <` / `std::` | cpp |
| `using System;` / `namespace ...` | csharp |
| `package main` / `func ` / `fmt.` | go |
| `public class` / `import java.` / `System.out` | java |
| `def ` + `:` / `import ` + `print(` | python |
| `SELECT ... FROM` / `CREATE TABLE` / `INSERT INTO` | sql |
| `interface ` / 类型注解 `: string` / `import ... from '@/` | typescript |
| `console.log` / `function ` / `const ... =>` / `require(` | javascript |
| `<html` / `<div` / `<!DOCTYPE` | html |
| `color:` / `margin:` 等 CSS 属性 | css |
| `"key":` 且整体可被 JSON.parse 解析 | json |
| 全部未命中 | plaintext（保留原文，用户可手动下拉改） |

> 自动识别只在"粘贴进空代码块"时触发；已有内容追加粘贴、或手动输入，一律不覆盖已选语言。

**F4 自动保存（数据安全底线）**

- 停止输入 800ms 自动落盘；Ctrl+S 立即落盘；窗口关闭前强制落盘
- 写入方式：写临时文件 → 落盘 → 原子 rename，杜绝半个文件
- 验收：任务管理器强杀进程，重开后最多丢最后 0.8 秒内容

**F5 全局搜索（Ctrl+K）**

- 跨笔记本搜索标题 + 正文，结果列表显示笔记本 / 分区 / 标题 / 命中片段（关键词高亮）
- ↑↓ 选择，回车跳转并滚动到命中位置
- 验收：5000 页 / 20MB 数据，输入即出结果，响应 < 150ms

**F6 主题**

- 浅色 / 深色一键切换，选择被记住；默认浅色

**F7 导出与备份**

- 单页导出 Markdown / HTML（代码块带高亮样式）
- 一键整库备份为 zip（文件名带时间戳）
- 自动备份：每天首次启动自动存一份，保留最近 10 份，超出自动清理最旧的
- 验收：导出 md 用 VSCode 打开，代码块格式正确

## 5. 界面规格

```
┌───────────┬──────────────┬────────────────────────────────┐
│ 笔记本     │ 分区          │  页面标题            [搜索] [☾] │
│  ▸ 我的笔记│ ● 工作       │ ────────────────────────────── │
│  ▸ 代码库  │ ● 学习       │  B  I  U  H1 H2 • 1. ☑ ❝ {} ▦  │
│  ▸ 速记    │ ● 代码库     │ ────────────────────────────── │
│           │ ● 回收站     │                                │
│           │ ───────────  │  正文编辑区                     │
│           │ 页面          │                                │
│           │ · 线程池参数  │  ┌──────────────────────────┐  │
│           │ · 常用 SQL    │  │ java            12 行  ⧉ │  │
```

- 三栏宽度可拖拽，每栏最小 160px，宽度被记住
- 右键菜单：重命名 / 复制 / 删除 / 导出 / 上移下移
- 空状态：无页面时显示「新建页面」引导，不出现空白面板
- 所有破坏性操作有确认弹窗，删除提示「可在回收站恢复」

## 6. 数据模型

```
D:\vswork\Jam\

  data\
    data.json        # 全部笔记本与页面
    backups\         # 自动备份 zip，保留最近 10 份
```

- 项目源码与数据统一放 `D:\vswork\Jam`：源码在根目录，构建产物在 `dist\` 与 `release\`，运行期数据在 `data\`
- 开发期数据写 `D:\vswork\Jam\data`；打包后写 exe 同目录，保证"拷贝文件夹即迁移"

```json
{
  "version": 1,

  "notebooks": [
    { "id": "nb_1", "title": "代码库", "sections": [
      { "id": "sec_1", "title": "常用 SQL", "color": "#7c5cff", "pages": [
        { "id": "pg_1", "title": "分页查询", "updatedAt": "...",
```

- 正文用 ProseMirror JSON（结构稳定、可无损还原、便于搜索）
- 单页超过 1MB 时给出提示，建议拆分

## 7. 技术架构

| 层 | 选型 | 说明 |
|---|---|---|
| 壳 | Electron 33 | 渲染层用 Web 技术，OneNote 式 UI 好做，可打便携 exe |
| 渲染 | React 18 + TypeScript + Vite | 类型约束，构建快 |
| 编辑器 | TipTap 2（ProseMirror） | 富文本与代码块同源，复制粘贴行为可控 |
| 高亮 | lowlight + highlight.js | 30+ 语言，纯本地，无网络依赖 |
| 存储 | 单个 JSON 文件 + 原子写 | 不用 SQLite：免原生模块编译、便携、备份=复制一个文件 |
| 搜索 | 内存索引（启动时构建） | 单人数据量下比全文索引更简单，5 万页以内无压力 |
| 打包 | electron-builder → portable | 产出单个 exe |

主进程只做三件事：读写数据文件、原子落盘、打开数据目录。渲染进程无 Node 权限，通过 preload 暴露 3 个方法（load / save / openFolder），杜绝渲染层乱写文件。

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 打包时下载 Electron / NSIS 失败 | 使用国内镜像源；失败则退回「免安装绿色目录」形式交付 |
| 杀毒软件误报 portable exe | 无签名证书，属常见误报；提供目录版兜底，并说明信任方式 |
| 超长页面（几千行代码）卡顿 | 代码块虚拟化不做，改为超过 500 行提示拆分；实测后定阈值 |
| 数据文件损坏 | 原子写 + 每日自动备份，恢复入口做在设置里 |
| 需求变更多 | 分阶段交付，P1 功能不进第一版 |
